# Airtable inventory

Every place the website still reads or writes Airtable, or depends on Airtable's shapes, as of `main` at 3bd2a7cf (2026-11-21). It is the checklist for pauseai-civicrm#1278 (tracked under pauseai-civicrm#1284): Airtable goes read-only on 5 Dec, when its writes start failing, and closes on 18 Dec. Once every **Code** row is gone or switched off, no website code calls Airtable.

The only Airtable base the website uses is PauseAI Volunteers & Actions (`appWPTGqZmUcs3NWu`). The UK politicians base is no longer needed or used (21 Nov), and no website code reads it, so it has no rows here. Statuses below are from pauseai-civicrm#1278 and #1284 as of 21 Nov.

Line numbers are for 3bd2a7cf and drift as PRs merge (#1279 rewrites rows 1, 2 and 13), so each row also names the function or constant. To redo the search on a later `main`:

```sh
grep -rniE 'airtable|app[A-Za-z0-9]{14}|tbl[A-Za-z0-9]{14}|pag[A-Za-z0-9]{14}' src scripts .github static messages template.env package.json netlify.toml
```

"Covered by" names the PR that moves the flow to CiviCRM: #1266 (statement, `STATEMENT_BACKEND`), #1280 and #1281 (national chapters), #1286 (`CRM_URL` and `CRM_KEY`), #1283 (/verify fix), #1305 (Contact Us through the CRM), #1308 (record-id Members links, `MEMBER_LINK_BACKEND`), all merged, and #1279 (new signups, `SIGNUP_BACKEND`), open. A flow behind a flag still calls Airtable until the flag is set in Netlify and the Airtable branch is deleted. Production flag states are as pauseai-civicrm#1278 records them; where it doesn't, the column says what the code does with the flag unset.
